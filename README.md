**❔ Why This Mod Is Made?**
Following With The Release Of Minecraft 26.2 And It's Snapshots, Now The Game Features A Vulkan API To Choose As Graphics API. The Goal Of Adding Vulkan Is To Improve The Performance And Stability Of The Game. While Most Modern PCs And Laptops Support Vulkan, Some Older Devices Don't. Vulkan Extension Emulator (VEE) Allows Players With Unsupported Devices And Missing Vulkan Extensions To Play The Game With Vulkan API. Also Mojang Has Officially Stated That After Enough Testing, Vulkan Will Be The Main Graphics API And OpenGL Will Be Removed. This Mod Is Aimed To Make Vulkan API Useable Across A More Wider Range Of Players.

**⚙️ How Does This Mod Work?**
In The Technical Side, Nothing Much Complex. This Mod Uses Virtual Software Emulation To Emulate The Missing Extensions And Features To Run Vulkan API. It Includes:

- VK_KHR_dynamic_rendering
- VK_KHR_synchronization2
- VK_KHR_push_descriptor
- VK_EXT_vertex_attribute_divisor
- VK_EXT_multi_draw
- Vulkan 1.2 Emulation

Also This Mod Has A Fallback System According To Your Graphics Driver Abilities. It Won't Emulate The Extensions Or Features That Your Driver Is Capable Of. It Will Only Emulate The Ones Missing Or Not Present. Which Means It Doesn't Stop Your GPU And Driver From Using It's Own Capabilities.

**⚠️ Caution**

- This Mod Is Still In Experimental Stage So Bugs Can Occur.

- This Mod Is Made To Work On As Much Devices As Possible, However It's Not Guaranteed To Work On All Devices. Especially, Lower Chances On Older Hardware.

- Performance May Vary Depending On Device, GPU And Graphics Driver.

**👍 Recommendations**
This Mod Is Also Supported With Using Sodium With Vulkan API. So It's Recommended To Use It With [Sodium](https://modrinth.com/mod/sodium) For A Overall Stable Experience. More Performance Mods Can Be Added For Further Better Experience.

**🌅 Shaders Support**
VEE Fully Supports Shaders. Download [Vitrail Shaders](https://modrinth.com/project/oSIKhgz3) And Sodium And Use Shaders. But If You Occur Any Graphical Issues Or Bugs, That Could Be Caused By Device GPU Weakness. Although It's Not Supposed To Happen.
